# Home

My knowledge bank. Everything here is plain Markdown, readable by Obsidian, Neovim or any text editor.

## How this vault works

| Folder | What goes in it |
| --- | --- |
| [[Inbox]] | Quick captures. Empty it every day or two. |
| `Daily/` | One note per day: focus, log, what I learned. |
| `Notes/` | Permanent notes: one idea per note, in my own words, linked to others. |
| `Sources/` | One note per book, article, paper, course or video. |
| `Attachments/` | Images and PDFs pasted into notes. |
| `Templates/` | Templates for daily, note and source. |

## The loop

1. **Capture**: `Super+K C` (a thought) or `Super+K P` (copied text). Don't organise, just capture.
2. **Process**: open [[Inbox]] and turn each item into a note, link it to an existing note, or delete it.
3. **Connect**: link notes with `[[double brackets]]`. Add `#review` to anything worth revisiting.
4. **Review**: `Super+K R` shows tagged notes plus a few you haven't touched in a month.
